PERSONAL ARCHIVE UTILITY

Ohio recorder uploads

A private, single-operator utility that uses rclone to back up recorder files to the operator's Google Drive and verify archived copies.

The app uploads selected recorder files, lists archive metadata, checks file integrity, and downloads archived copies when needed for verification or recovery. It is not a public file-sharing service and does not offer account registration.

Google authorization is used only for the operator's archive workflow. The requested Drive permission permits reading, creating, editing and deleting files; this broad scope is needed to access existing archives created with the previous client. Actual operations are limited to the configured archive locations.

This public website contains only app information. It does not contain recordings, private account data, access tokens, or client secrets.
